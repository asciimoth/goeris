# ERIS specifications

This directory keeps local copies of the ERIS specification and the ERIS
Extensions and Recommendations (EER) documents. The copies are unchanged. Use
them when the upstream pages are unavailable.

- [ERIS 1.0.0 specification](eris-v1.0.0.html)
- [CBOR serialization](eer/cbor/index.md)
- [ERIS-FS](eer/eris-fs/index.md) (version 2, with version 1 read support)
- [DNSLink records](eer/dnslink/index.md)
- [ERIS over HTTP](eer/http/index.md)
- [Object storage](eer/object-storage/index.md)
- [ERIS over CoAP](eer/coap/index.md)
- [Link files](eer/linkfile/index.md)
- [Magnet URIs](eer/magnet-uri/index.md)
- [SQLite block storage](eer/sqlite/index.md)
- [RDF](eer/rdf/index.md)
- [Canons](eer/canons/index.md)
- [Cache vocabulary](eer/cache-vocabulary/index.md)

This repository also defines original encoding policies under the repository's
CC0 license:

- [ERIS-FS automatic compression policy v1](eris-fs-auto-compression.md)
- [ERIS-FS v2 encoding and reproducibility](eris-fs-encoding.md)

The ERIS 1.0.0 HTML file comes from the
[ERIS specification repository](https://codeberg.org/eris/spec) at commit
`77982f9e8a92f97a02aea5084f7d475bd9a42354`. The EER files come from the
[EER repository](https://codeberg.org/eris/eer) at commit
`bc6e7d2bb2842d0a6fa01436d5d26de0184dd660`. The upstream pages are normally
published at [purl.org/eris](https://purl.org/eris) and
[eris.codeberg.page/eer](https://eris.codeberg.page/eer/).

Keep this attribution, the source links, and the license with redistributed

original documentation, not to these upstream copies.

The copied documents keep their upstream links. Some of those links depend on
the upstream site. Use the local links above to read the copies in this tree.
